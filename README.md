# Python Disease Simulator

**Course:** Fundamentals of Programming (Curtin University)

**Overview**
This repository contains a Python-based disease simulation tool developed as a final project for the Fundamentals of Programming unit. The project demonstrates core programming concepts, including data tracking and algorithmic simulation of spread dynamics.

**Files Included**
* `diseaseSim.py`: The main application script that executes the simulation.
* `Readme_diseasesim.txt`: Original assignment documentation and runtime instructions.
* `Report_FOP_Assignement.pdf`: Comprehensive project report detailing the simulation's design, logic, and outcomes.

**Technical Skills Demonstrated**
* **Language:** Python 3
* **Concepts:** File I/O operations, algorithmic logic, and data simulation.
