How to run the program for Disease Simulation

Main Requirements
Before running the simulation, ensure Python 3.x and the necessary libraries (numpy and matplotlib) are installed. An IDE such as Spyder or Jupyter Notebook is recommended for ease of use.
Running the Simulation
    1. Open the code file in your IDE.
    2. Run the script. The program will prompt for the following inputs:
        ◦ Grid size (rows and columns).
        ◦ Number of simulation steps.
        ◦ Initial population size.
        ◦ Initial infected population.
        ◦ Neighborhood type (moore or von Neumann).
        
   3. The program will display a visualization of the simulation at each step and output the final statistics.
